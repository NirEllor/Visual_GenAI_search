  Knowledge Distillation for Latent Flow Matching — CIFAR-10

────────────────────────────────────────────────────────────────────────────────
1. AUTOENCODERS  (PyTorch — frozen after Step 0)
────────────────────────────────────────────────────────────────────────────────

Source      : Custom ConvAutoencoder  (models/autoencoder.py)
Framework   : PyTorch
Type        : Variational Autoencoder (VAE) with reparameterization
Input       : CIFAR-10 images  (B, 3, 32, 32),  pixel values in [0, 1]
Latent dims : 64, 128, 256, 384, 512, 1024
              latent_channels = latent_dim // 16  (since spatial map is 4×4)

Encoder
-------
  Conv(3→16,  3×3, stride=2, padding=1) → BatchNorm2d(16)  → ReLU  # (B, 16, 16, 16)
  Conv(16→32, 3×3, stride=2, padding=1) → BatchNorm2d(32)  → ReLU  # (B, 32,  8,  8)
  Conv(32→64, 3×3, stride=2, padding=1) → BatchNorm2d(64)  → ReLU  # (B, 64,  4,  4)
  ┌─ encoder_mean   : Conv2d(64→C, 1×1)   → (B, C, 4, 4)
  └─ encoder_logvar : Conv2d(64→C, 1×1)   → (B, C, 4, 4)  (clamped to [−30, 20])
  Reparameterization: z = mean + ε · exp(0.5 · logvar),  ε ~ N(0, I)
  Flatten:  z, mean, logvar  →  (B, latent_dim)   [= (B, C·16)]

  Note: encoder_conv (3→16→32→64) is a fixed feature extractor;
        encoder_mean / encoder_logvar are the experimental variable (bottleneck width C).
        No FC linear layer — bottleneck capacity is controlled entirely by channel width C.

Decoder  (mirrors encoder)
-------
  Reshape z   (B, latent_dim) → (B, C, 4, 4)
  decoder_proj : Conv2d(C→64, 1×1)                                    # (B, 64, 4, 4)
  decoder_refine (stays at 4×4 before upsampling):
    Conv2d(64→64, 3×3, padding=1) → BatchNorm2d(64) → ReLU           # (B, 64, 4, 4)
    Conv2d(64→64, 3×3, padding=1) → BatchNorm2d(64) → ReLU           # (B, 64, 4, 4)
  ConvTranspose2d(64→32, 3×3, stride=2, padding=1, out_padding=1) → BatchNorm2d(32) → ReLU  # (B, 32, 8, 8)
  ConvTranspose2d(32→16, 3×3, stride=2, padding=1, out_padding=1) → BatchNorm2d(16) → ReLU  # (B, 16, 16, 16)
  ConvTranspose2d(16→3,  3×3, stride=2, padding=1, out_padding=1)                            # (B, 3, 32, 32)

Step 0 — Autoencoder training  (all 6 dims)
-------------------------------------------
  Objective   : LPIPS (VGG backbone, frozen) — perceptual loss
  Optimizer   : AdamW  (lr=2e-3)
  Epochs      : 1000
  Batch size  : 128
  LR schedule : CosineAnnealingLR  (T_max=1000, η_min=lr·0.01)
  Gradient clip: 5.0 (global norm)
  EMA decay   : 0.9999
  Output      : checkpoints/ae_{64,128,256,384,512,1024}.pt
                (keys: model_state_dict, latent_dim, latent_mean, latent_std, loss_history)


────────────────────────────────────────────────────────────────────────────────
2. GENERATIVE MODEL — FLOW MATCHING (Rectified Flow)
────────────────────────────────────────────────────────────────────────────────

Source   : models/diffusion.py  (FlowMatching class)
Type     : Straight-line interpolation / constant-velocity flow

Forward process (training)
  x_0 : clean data latent
  x_1 : Gaussian noise  ~ N(0, I)
  t   : ~ U[0, 1]
  x_t = (1 − t) · x_0  +  t · x_1          (interpolation)
  v   = x_1 − x_0                           (constant target velocity)
  loss = MSE( v_theta(x_t, t),  v )

Reverse sampling (Euler ODE, n_steps=50)
  x ← N(0, I)            # t = 1  (pure noise)
  dt = 1 / n_steps
  for t = 1.0, 1−dt, ..., dt:
      x ← x − v_theta(x, t) · dt
  return x               # t = 0  (data)


────────────────────────────────────────────────────────────────────────────────
3. DENOISER ARCHITECTURE  (PyTorch — velocity network)
────────────────────────────────────────────────────────────────────────────────

Source   : models/denoiser.py  (ConvDenoiser, TeacherDenoiser, StudentDenoiser)

Both teacher and student predict velocity v_theta(x_t, t) → (B, latent_dim).
Latents are processed as (C, 4, 4) spatial feature maps, not as flat vectors.

Shared components
-----------------
  SinusoidalPosEmb(time_emb_dim=256)
    → frequencies:  exp(−log(10000) · i / (half−1)),  i ∈ [0, half)
    → output:  [sin(t·freq), cos(t·freq)]  concatenated  → (B, 256)
    (input t is scaled ×1000 before embedding)

  Time-embedding MLP
    SinPosEmb(256) → Linear(256→256) → GELU → Linear(256→256)   → t_emb (B, 256)

  ConvResBlock(channels, time_emb_dim=256)   — FiLM conditioning
    GroupNorm(min(32, channels), channels)
    Conv2d(channels→channels, 3×3, padding=1)
    GroupNorm(min(32, channels), channels)
    Conv2d(channels→channels, 3×3, padding=1)
    time_proj: Linear(256 → 2·channels)  →  scale (B, channels, 1, 1) + shift (B, channels, 1, 1)
    forward: h = GELU(conv1(norm1(x))) · (1 + scale) + shift
             h = conv2(norm2(h))
             return x + h

  Output head
    GroupNorm(min(32, hidden_channels), hidden_channels)
    Conv2d(hidden_channels→C, 1×1)   # predicts velocity spatial map

Full forward pass
  x_t  (B, latent_dim)
       → reshape  (B, C, 4, 4)
       → input_proj: Conv2d(C → hidden_channels, 1×1)   → (B, hidden_channels, 4, 4)
       → N × ConvResBlock(hidden_channels, t_emb=256)
       → output_head: GroupNorm → Conv2d(hidden_channels → C, 1×1)  → (B, C, 4, 4)
       → flatten  →  v_pred (B, latent_dim)

Teacher (step 2)
  n_blocks       : 8
  hidden_channels: max(256, latent_channels × 8)   [scales with latent_dim]
  e.g. dim=64  → C=4,   hidden=256
       dim=128 → C=8,   hidden=256
       dim=256 → C=16,  hidden=256
       dim=384 → C=24,  hidden=256
       dim=512 → C=32,  hidden=256 (tie)
       dim=1024→ C=64,  hidden=512

Student (step 3b)
  n_blocks       : 4
  hidden_channels: max(128, latent_channels × 8)   [scales with latent_dim]
  e.g. dim=64  → C=4,   hidden=128
       dim=128 → C=8,   hidden=128
       dim=256 → C=16,  hidden=128
       dim=384 → C=24,  hidden=192
       dim=512 → C=32,  hidden=256
       dim=1024→ C=64,  hidden=512


────────────────────────────────────────────────────────────────────────────────
4. TRAINING HYPERPARAMETERS
────────────────────────────────────────────────────────────────────────────────

Step 2 — Teacher training  (step2_train_teachers.py)
  Input       : normalised latents from latents/latents_{dim}.npy
  Epochs      : 1000
  Batch size  : 256
  Optimizer   : AdamW  (lr=3e-4, weight_decay=1e-4)
  LR schedule : CosineAnnealingLR  (T_max=epochs, η_min=lr·0.01)
  Gradient clip: 1.0  (global norm)
  EMA decay   : 0.9999
  Loss        : MSE( v_pred, v_true )   [velocity prediction]
  Checkpoint  : every 50 epochs (interim), final at end
  Output      : models/teacher_{dim}.pt
                (keys: model_state_dict, latent_dim, latent_mean, latent_std, loss_history)

Step 3b — Student distillation  (step3b_distill.py)
  Approach    : combined flow matching + knowledge distillation
  Input       : synthetic/{dim}/synthetic_{dim}_{n}.npy  (normalised latents)
                + frozen teacher checkpoint models/teacher_{dim}.pt
  Epochs      : 500  (max; subject to early stopping)
  Batch size  : 256
  Optimizer   : AdamW  (lr=1e-4, weight_decay=1e-4)
  LR schedule : CosineAnnealingLR  (T_max=epochs, η_min=lr·0.01)
  Gradient clip: 1.0  (global norm)
  EMA decay   : 0.9999
  Early stop  : patience=50 epochs, min_delta=1e-4  (saves best EMA state)
  Loss        : 0.5 · MSE(v_pred, v_target) + 0.5 · MSE(v_pred, v_teacher)
                  loss_flow = MSE( v_pred, x_1 − x_0 )          [flow matching]
                  loss_kd   = MSE( v_pred, teacher(x_t, t) )    [KD imitation]
                  x_1 and t sampled once per batch; shared by x_t, v_target, and teacher call
  Output      : models/student_{dim}_{n_samples}.pt

Latent normalisation
  Per-dimension zero-mean unit-variance (computed from CIFAR-10 train latents)
  Stats saved to latents/latents_{dim}_norm_stats.npy
  Denormalisation applied at decode time using saved mean/std

5. SYNTHETIC DATA GENERATION  (step3a_generate.py)
────────────────────────────────────────────────────────────────────────────────

  Source model  : teacher EMA weights
  Sampling      : Euler ODE, 50 steps, batch=2048
  Dataset sizes : 50k, 100k, 150k, 200k samples per dim (float32 memmap)
  Trajectory    : 50k × 51 frames × dim  (float16 memmap)  — for analysis
  Output        : synthetic/{dim}/synthetic_{dim}_{n}.npy
                  synthetic/{dim}/trajectories_{dim}.npy

6. EVALUATION  (step4_evaluate.py)
────────────────────────────────────────────────────────────────────────────────

  Phases (independently restartable via flags):
    --generate : Euler sampling (50 steps) → 10k latent samples → denormalise → .npy
    --decode   : AE decoder → PNG images; reconstructs CIFAR-10 test set for AE-FID baseline
    --metrics  : FID (clean-fid vs CIFAR-10 train), IS (torch-fidelity), AE-FID
    --plot     : fid_vs_size.png, fid_vs_dim.png, unified metrics_all.json

  Generated images : 10 000 per (dim, size) combination
  Sampling         : Euler 50 steps → denormalise → AE decode → PNG
  Metrics          : FID (clean-fid),  IS (torch-fidelity),  AE-FID
  Output           : results/trained_AE/
